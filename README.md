# Siemens NX CAM 工單自動化匯出系統 (NX CAM to Excel)

專為 Siemens NX CAM 打造之智慧工單自動化匯出系統。能自動提取 CAM 導覽器中選取的程式群組或工序數據，依據標準工單母版（`ShopDoc_Template.xlsx`）自動完成智慧刀具合併、流水序號編排、工段區隔分頁、以及**互動引導式 3D 視角截圖實體內嵌**，一鍵產出格式嚴整的生產工單。

---

## 🌟 核心功能特色

### 1. 彈性選取與程式檔名規範
- **直接選取工序**：
  - 在 CAM 導覽器中直接點選一或多道工序時，程式檔名自動設為**該工序自身名稱**（每道工序皆各自顯示其名稱）。
- **透過資料夾（NCGroup）展開**：
  - 以母工段／父資料夾為基準，**僅該工段首道工步填寫頂層父資料夾名稱（如 `MK-1-M1`），同工段後續工步全數留空**。
- **重疊選取自動防護（去重機制）**：
  - 若操作時同時選中了父資料夾以及內部工序，系統透過底層標籤去重，確保**每道工序僅輸出一次**，絕不重複輸出，且維持導覽器物理排版順序。

### 2. 刀號與工步智慧合併機制
- **各子資料夾獨立合併**：
  - 嚴格依照導覽器物理順序處理，不同子資料夾即使使用相同刀號亦絕不跨子資料夾合併工步與時間。
- **狀況 A（同刀號工序累加）**：
  - 同一子資料夾內連續使用相同刀號時，工步自動合併為同一列，加工時間自動累計加總，並保留切削轉速與進給資訊。
- **狀況 B（連續刀號工步合併）**：
  - 若在同一子資料夾內使用連續刀號且規格完全相同（如 T01、T02），刀號欄位自動標註為 `T01~T02`，加工時間加總，長度採安全最大值防護。
- **狀況 C（單獨選取之工序各自獨立成列）**：
  - 若為工程師直接單獨選取之工序，代表指定獨立加工與轉出，絕不參與同刀號/連續刀具合併，每道工序各自獨立成列並顯示各自工序名稱（與 NC 後處理各自轉出對應檔案完全一致）。

### 3. 刀具規格與素材尺寸解析
- **刀具規格智慧格式化**：
  - 直徑若帶有 `D` 前綴（如 `D12`、`D10.0`）自動清理為純數字，呈現如 `EM (12.0)`、`R球刀 (6.0)`。
- **素材尺寸全域智慧提取**：
  - 支援從群組名稱解析（如 `160x160x10-P1`）、掃描包含「尺寸」、「素材」、「BLANK」、「STOCK」關鍵字之群組，或透過全域 CAM WORKPIECE 與實體包容盒精確計算尺寸。

### 4. 互動式 NC 後處理轉出與工單設定視窗 (NC Post Dialog)
- **選取項目自動轉化為 NC 程式任務**：
  - **父資料夾合併為單一 NC 檔**：選取父資料夾時，其內部所有子資料夾工序一同彙整為單一 NC 檔（檔名如 `MK-1-M1.nc`）。
  - **多資料夾各自獨立轉出**：同時選取複數資料夾時，各自轉出對應的 NC 檔。
  - **單獨工序獨立轉出**：單獨點選之工序，自動以工序名稱命名轉出對應 NC 檔。
  - **重疊選取去重防護**：若父資料夾已選，其內部已被包含之子資料夾或工序不重複產生獨立檔案。
- **機台後處理器自動解析**：
  - 自動讀取 NX 安裝環境之 `template_post.dat`，下拉選單即刻呈現本機可用機台清單（如 `Fanuc_2026`、`840D_5axis`、`YCM_noCheck` 等），並支援自訂瀏覽外部 `.tcl`/`.def`。
- **三態彈性決策**：
  - 【🚀 轉出 NC 碼並匯出工單】：一鍵完成後處理 NC 碼轉出與 Excel 工單產出。
  - 【📋 僅匯出工單 (不轉 NC)】：跳過後處理，專注產出工單。
  - 【❌ 取消】：中止操作。

### 5. 互動引導式拍照精靈 (Capture Assistant)
- **置頂非獨占懸浮視窗**：
  - 拍照視窗永遠置頂於螢幕前端，不凍結 NX 畫面；工程師可直接在 NX 主繪圖區用滑鼠中鍵任意 3D 旋轉、縮放工件。
- **F8 原生視圖貼齊**：
  - 支援鍵盤 F8 或點擊視窗按鈕一鍵貼齊正交視角。
- **白底高清晰渲染與實體內嵌**：
  - 自動以純白底色渲染截圖，不浪費列印墨水。
  - 截圖直接等比例居中內嵌於 Excel 展示區（A18:J36），採用實體封裝（`SaveWithDocument = True`），移至其他電腦開啟絕不遺失圖片。

### 6. 工單可視化互動分頁排版編輯器 (Interactive Pagination Engine)
- **可視化自由拖曳排版與檔名群組連動 (Group Integrity)**：
  - 系統彈出專屬【工單可視化互動式分頁排版編輯器】，以「系統智慧推薦排版」為初始基礎，工程師可直觀檢視。
  - **以程式檔名為群組整體移動**：所有工步排序與跨頁操作嚴格以程式檔名為群組連動，確保 NC 程式刀具工藝不被打散；點選任一刀具自動聯動全選整個程式群組。
  - 表格中清楚顯示程式檔名（首行『📁 檔名』，後續刀具顯示縮排『↳ (同上: 檔名)』），絕無空白列。
  - 支援以滑鼠直接拖曳群組調整順序或跨頁拖曳；亦提供【⬆ 群組上移】、【⬇ 群組下移】、【⬅ 群組移至上一頁】、【➔ 群組移至下一頁】、【移動群組】與【📄 選取群組獨立成新頁】操作。
- **跨工段合併與示圖智慧關聯 (選項 1.A)**：
  - 若將不同工段（如 M1、M2）合併於同一頁，系統預設自動以該頁「工步數量較多之工段」為關聯示圖與原點，亦提供下拉選單供工程師自由切換。
- **單頁延伸與示圖微縮機制 (選項 2.A)**：
  - 每頁標準為 10 格（綠燈）；若單頁分配 11~15 格自動向下擴增（黃燈）；16~20 格同頁微縮示圖（橘燈）；超過 20 刀自動延伸整頁，示圖自動移至專屬大圖頁（藍燈）。
- **序號欄直接內聯輸入工段標記 (Direct In-cell Editing)**：
  - **直接在序號欄中輸入更直觀**：工程師可直接在表格「序號 / 標記」儲存格雙擊 (或按 F2) 直接輸入文字 (如 OP10、正面粗銑)。
  - **若使用者有輸入，序號完全依照輸入文字顯示，不須再加流水序號**；清空則自動恢復風格流水號。
- **群組截圖決定與示圖排版模式 (預設不勾選)**：
  - **截圖勾選欄只對「程式群組」生效**：僅在群組首行顯示截圖狀態 (☐ 略過 / ☑ 截圖)，同群組後續刀具保持留空，避免誤解；可直接單擊該欄快速切換。
  - **預設為不勾選**：預設全工單皆為純刀具清單頁面，只有工程師主動勾選之程式群組才會進行拍照與產出示圖。
  - **示圖排版模式**：
    - 1. 工序後加圖片 (同頁下方/工序緊隨)：同頁下方預留示圖展示區；若該頁皆未勾選截圖則自動轉為純刀具頁面。
    - 2. 圖片統一置於最後一頁 (大圖附圖頁)：前面頁面全數排滿刀具清單，最後自動為所有勾選截圖之工段建立獨立專屬大圖頁。
  - **拍照精靈智慧連動**：若全工單皆未勾選截圖，流程自動略過拍照精靈，完全不打擾工程師。
- **多元序號編排風格切換**：
  - 預設維持「每頁獨立流水序號 (1, 2, 3...)」，並支援下拉即時切換「工段前綴 (M1-01, M2-01...)」、「全工單連續 (1, 2... 15, 16)」、「兩位數補零 (01, 02...)」與「工藝步長 (10, 20...)」。

## 🚀 快速安裝與使用

### 步驟 1：放置檔案
將專案檔案複製至指定目錄：
`C:\NX_Standard\Template\`

### 步驟 2：在 NX CAM 介面中新增快速功能按鈕
1. 在 NX 空白工具列處按右鍵，點選 **自訂 (Customize)**（或按快捷鍵 `Ctrl + 1`）。
2. 在彈出的視窗中切換至 **指令 (Commands)** 標籤頁。
3. 選擇 **新建項目 (New Item)**，將右側的 **使用者定義按鈕 (User Defined Button)** 拖曳至 CAM 工具列中。
4. 在該按鈕上按右鍵點選 **編輯動作 (Edit Action)**：
   - **類型**：選擇 `Journal` 或 `Python`
   - **檔案**：選取 `C:\NX_Standard\Template\nx_cam_to_excel.py`
5. （選用）修改按鈕圖示與名稱為「匯出工單(帶示圖)」。

### 步驟 3：執行匯出
1. 在 NX CAM 工序導覽器中，選取欲匯出的資料夾或工序。
2. 點擊「匯出工單」按鈕。
3. 依據拍照小精靈引導旋轉視角並截圖（或按略過）。
4. 系統自動產出並開啟格式完整的 Excel 工單。
